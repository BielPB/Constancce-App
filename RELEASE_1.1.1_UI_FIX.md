# Constancce 1.1.1 — Ajustes de interface

## Alterações

1. Quadro de tarefas
- Corrigido overflow dos botões Foco, Adiar, Editar e Excluir.
- Os controles agora se adaptam à largura do card nas cinco colunas.
- Cards e colunas passam a conter corretamente todo o conteúdo.

2. Sidebar
- Rotina: Hoje, Hábitos, Tarefas.
- Saúde: Treinos, Dieta.
- Planejamento: Finanças, Calendário, Metas.
- Evolução: Progresso, Conquistas, Relatórios.
- Social: Amigos.
- Conta: Perfil, Notificações.
- Os títulos de grupo não são mais repetidos quando módulos de áreas distintas estavam intercalados.

Nenhuma Edge Function, SQL, integração do Mercado Pago ou regra de sincronização foi alterada nesta release.
