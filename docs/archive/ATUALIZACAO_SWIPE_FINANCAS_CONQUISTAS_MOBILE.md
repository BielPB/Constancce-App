# CONSTANCCE — SWIPE, FINANÇAS, CONQUISTAS E MOBILE

## Navegação mobile
A passagem horizontal agora segue exatamente a ordem visual do menu mobile:
Hoje → Treinos → Hábitos → Finanças → Perfil → itens do menu Mais.

## Finanças — Contas a pagar
- contas podem ser editadas;
- contas pendentes podem ser marcadas como pagas;
- contas pagas podem ser desmarcadas com confirmação;
- ao desmarcar, o lançamento financeiro criado pelo pagamento é removido;
- se uma conta já paga for editada, o lançamento correspondente é atualizado.

## Gráfico — Evolução nos últimos 6 meses
- gráfico agora é interativo;
- toque/clique no mês ou nas linhas;
- exibe Entradas e Saídas daquele mês com valores em reais.

## Lançamentos do mês
- mostra todos os lançamentos do mês, não apenas os 8 mais recentes;
- filtro por tipo: entradas/saídas;
- filtro dinâmico por descrição cadastrada;
- novas descrições como Cartão, iFood ou Jogo passam a aparecer automaticamente;
- descrições longas são mostradas por completo;
- layout refeito para celular.

## Conquistas
Critérios agora são objetivos e baseados no maior streak já alcançado:
- Comum: 45 dias consecutivos;
- Rara: 90 dias consecutivos;
- Épico: 180 dias consecutivos;
- Lendário: 365 dias consecutivos (1 ano).

Cada card explica:
- como desbloquear;
- período necessário;
- progresso atual;
- quantos dias faltam;
- prêmio correspondente.

Depois de desbloqueado, o nível permanece conquistado porque é calculado pelo maior streak histórico.

## Responsividade
- textos longos quebram corretamente;
- lançamentos e contas não comprimem valores/botões;
- filtros usam largura total no celular;
- cards de conquistas foram refinados para telas pequenas;
- ajustes adicionais para celulares de até 380px.

Nenhum SQL novo é necessário para esta atualização.
