# Atualização de interface

- Tipografia geral alterada para Poppins (400, 500, 600, 700 e 800).
- Poppins aplicada também a títulos, números, campos e botões.
- Cards ganharam melhor profundidade, contraste, bordas e sombras.
- Botões primários receberam acabamento mais forte e estados de interação.
- Inputs e selects ganharam foco visual mais claro.
- Sidebar desktop foi ampliada e recebeu estado ativo mais evidente.
- Barra de navegação mobile recebeu efeito de vidro, safe area e melhor espaçamento.
- Área principal ganhou largura maior em desktop e respiro adicional no mobile.
- Dashboard “Hoje” ganhou cabeçalho visual mais hierárquico para streak e progresso.
- Tema claro e escuro continuam suportados.
- Nenhuma lógica de hábitos, metas, treinos, checklists, gamificação ou sincronização foi removida.
