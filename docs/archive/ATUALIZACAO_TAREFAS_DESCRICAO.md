# CONSTANCCE — DESCRIÇÃO E SUBTAREFAS

## Nova tarefa / Editar tarefa
- Novo campo "Descrição (opcional)".
- Aceita textos maiores com contexto, observações e instruções.
- A descrição é salva junto com a tarefa e sincronizada normalmente.

## Visualização
- Modo Foco mostra a descrição completa.
- Subtarefas continuam interativas dentro do Modo Foco.
- Cards do Kanban mostram descrição e até 3 subtarefas.
- Minha Semana mostra a descrição e quantidade de subtarefas.
- Calendário mostra descrição e lista de subtarefas da tarefa selecionada.
- Hoje sinaliza quando a tarefa possui descrição/subtarefas.

Nenhum SQL novo é necessário.
