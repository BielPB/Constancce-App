# Atualização Constancce

- Nome do produto atualizado para Constancce.
- Sincronização alinhada à coluna `user_id` do Supabase/RLS.
- Salvamento local imediato e autosave remoto de todo o estado.
- Retry automático quando a conexão volta, sem banner invasivo.
- Status discreto: Salvo / Salvando… / Offline.
- Sidebar permanece fixa no desktop; apenas o conteúdo principal rola.
- Foto de perfil por usuário, otimizada e sincronizada dentro do perfil.
- Favicon e ícones para navegador, iOS e instalação mobile.
